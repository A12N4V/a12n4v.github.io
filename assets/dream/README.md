# Dream frames

`frames/0.jpg` to `frames/4.jpg` come from Google's DeepDream notebook (https://github.com/google/deepdream, Apache 2.0, 2015). They are, in order: the input sky, the sky dreamt at a low layer, then at the default layer, then guided by flowers, and finally frame 29 of the zoom.

The post-AI section walks through them with the scroll. To use other footage, replace these files with frames of the same aspect ratio (16:9).
